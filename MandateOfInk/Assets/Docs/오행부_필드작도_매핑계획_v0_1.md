# 오행부 필드 작도 매핑 계획 v0.1

작성 2026-07-27. 필드/퍼즐 작도 도입(사용자 결정)의 매핑 원칙·전체 배정표·구현 로드맵·미결 논점을 정리한 개발용 문서다.
원본 데이터는 `오행부_작도글자일람_v1_2.csv`(단일 진실) — 이 문서와 CSV가 어긋나면 CSV가 우선이며, 배정 수정은 CSV 수정 → 임포터 재실행으로 반영한다.

## 1. 결정 경위

- 동기: 전투용 작도 120자가 과다 — 일부를 필드(퍼즐·이동·상호작용)용으로 재배정해 전투 풀을 줄인다(사용자 결정).
- 제약: 중성을 새로 추가하지 않는다(ㅡ/ㅣ 특수 중성 도입안은 기각). 기존 120자 안에서 재배정.
- 채택 규칙: **음성(ㅓ/ㅜ) + 받침 = 필드 술식** — "양(발산)은 적에게, 음(수렴)에 거동을 얹으면 세상에 작용한다."
- 예외: 버프 소환수(ㅜ+ㄱ 5자)는 소환 유지. 음성 무받침 10자(패링·광역 방어)는 전투 유지.

## 2. 매핑 원칙 (유추 가능성 우선)

받침 부가효과는 그 받침의 동사에서 자연스럽게 유추되어야 한다(기존 확립 원칙). 필드 문맥에서:

| 축 | 의미 |
|---|---|
| 초성(오행) | 재료·성질: 목=생장·덩굴 / 화=열·빛·동력 / 토=땅·무게 / 금=쇠·날·기계 / 수=물·흐름 |
| 중성 ㅓ | 자신·단일 대상에 **건다** |
| 중성 ㅜ | 세상·영역에 **놓는다** |
| 받침 ㄱ | 붙듦·고정 (전투의 속박에서 유추) |
| 받침 ㄴ | 지속 (시간에 걸친 효과) |
| 받침 ㅁ | 설치 (구조물을 놓음 — 전투의 격발 설치에서 유추) |
| 받침 ㅅ | 뚫음·엶 (전투의 관통에서 유추) |
| 받침 ㅇ | 이음·연결 (전투의 연쇄에서 유추) |

## 3. 120자 조감 (전환 후)

| 구획 | 글자 수 | 용도 |
|---|---|---|
| 양성 ㅏ/ㅗ 전체 | 60 | **전투 공격** — 받침 5종 오행별 차별화 전부 유지(관통·연쇄·속박·지속·격발), ㅗ+ㄱ은 공격 소환 |
| 음성 ㅓ/ㅜ 무받침 | 10 | **전투 방어** — 단일 패링(거/너/머/서/어), 광역 방어(구/누/무/수/우) |
| 음성 ㅜ+ㄱ | 5 | **버프 소환수** (국/눅/묵/숙/욱) |
| 음성 ㅓ/ㅜ + 받침 | 45 | **필드 술식** (아래 표) |
| 합계 | 120 | 전투 75 / 필드 45 |

## 4. 필드 45자 전체 배정표

굵게 = 구현 완료(2026-07-27). 나머지는 예약(미구현) — 시전하면 로그+옅은 퍼프. 전부 [가정]이며 CSV 수정으로 교체 가능.

### ㅓ 계열 — 자신·단일에 건다 (25자)

| 받침 | 목(ㄱ) | 화(ㄴ) | 토(ㅁ) | 금(ㅅ) | 수(ㅇ) |
|---|---|---|---|---|---|
| ㄱ 붙듦 | 걱 덩굴 손(벽타기 홀드) | 넉 불씨 부착(조명) | 먹 무게 고정(밀림 저항) | 석 쇠 부착(금속면 매달림) | 억 수면 밟기 |
| ㄴ 지속 | 건 생기(체력 서서히 회복) | **넌 화력(차량 가속)** | 먼 바위 피부(피해 감소) | 선 날 세우기(베기 강화) | **언 수막(낙사 방어)** |
| ㅁ 설치 | 검 덩굴 줄(오르내림) | 넘 화톳불(거점 불) | 멈 디딤돌(공중 발판 1개) | 섬 쇠말뚝(고정 앵커) | 엄 샘(먹 회복) |
| ㅅ 뚫음 | 것 덤불 가르기 | 넛 녹여 뚫기(얼음·밀랍) | 멋 흙 뚫기(발굴) | 섯 절단(자물쇠·사슬) | 엇 물길 트기 |
| ㅇ 이음 | 겅 덩굴 그네(스윙) | 넝 불씨 잇기(점화) | 멍 징검돌 잇기 | 성 동력 잇기(기계 작동) | 엉 물살 잇기(부유물 밀기) |

### ㅜ 계열 — 세상·영역에 놓는다 (20자, ㄱ은 소환이므로 제외)

| 받침 | 목(ㄱ) | 화(ㄴ) | 토(ㅁ) | 금(ㅅ) | 수(ㅇ) |
|---|---|---|---|---|---|
| ㄴ 지속 | 군 생장 영역(초목 소생) | 눈 온기 영역(해빙·방한) | 문 굳힘 영역(늪·모래) | 순 자기장(쇠붙이 정렬) | 운 안개 영역(은신) |
| ㅁ 설치 | **굼 나무 기둥(도약)** | 눔 분출구(전방 발사) | **뭄 돌다리(절벽 잇기)** | 숨 철책(차단 울타리) | 움 물웅덩이(낙하 쿠션) |
| ㅅ 뚫음 | 굿 뿌리 뚫기 | 눗 광역 융해 | 뭇 함몰(구덩이) | 숫 광역 절단 | 웃 급류 가르기 |
| ㅇ 이음 | 궁 덩굴 그물(길 짜기) | 눙 봉화 연쇄(일괄 점등) | 뭉 징검돌 무리 | 숭 기관 연동(일괄 작동) | 웅 수로 연결(수위) |

## 5. 구현 로드맵

- 1차(완료): 뭄(돌다리)·굼(도약)·언(낙사 방어)·넌(차량 가속) + 낙사 피해 시스템 + 퍼즐 테스트 지형.
- 2차([제안] — §6의 전투 빈약 우려 대응을 겸함): 전투 중에도 쓸모 있는 필드 술식 우선 구현 — 먼(바위 피부)·건(생기)·운(안개)·숨(철책)·엄(먹 샘). 이 5종이 들어오면 "전투 유틸"이 사실상 복원된다.
- 3차 이후: 레벨(M2 수직 슬라이스) 퍼즐 기믹이 확정되는 순서대로 — 섯(자물쇠)·성/숭(기계 연동)은 황경 기관 장치와, 눗/눈(융해)은 설산 지형과 함께.

## 6. 전투 풀 축소 우려 분석 [제안 — 사람 판정 필요]

우려: "음성+받침 전체를 필드로 돌리면 전투 때 쓸 게 부족하지 않은가."

현황 분석:
- 전투 공격은 60자로 그대로다(단일/광역 × 받침 5종 × 오행 5종 — 최근 오행별 차별화 작업 전부 이 구획에 있음).
- 실제로 얇아진 것은 **전투 중 유틸리티**다. 전환 전 음성+받침은 "방어+부가효과" 조합이었는데(예: 광역 방어+관통 같은 어색한 조합 포함), 전환 후 방어는 무받침 2동사(패링·광역 막)만 남았다.
- 단, 필드 술식은 전투 중 시전이 금지되지 않는다. 먼(피해 감소)·건(회복)·운(안개)·숨(철책)·움(쿠션)·굼(도약 이탈)은 전투 유틸로 직접 기능하고, 뭄(다리)·멈(디딤돌)은 지형 활용 전술이 된다. 소울라이크에서 "전투 중 환경술"은 개성이 될 수 있다.

대응 옵션(택일 또는 병행, 사람 판정):
- A. 현행 유지 + 2차 구현을 전투 유틸 우선으로(§5) — 별도 재배정 없이 체감 해결. **추천.**
- B. ㅓ+받침 25자를 「행동 작도」(전투 겸용 유틸)로, ㅜ+받침 20자만 「필드 작도」로 분류 명칭 분리 — 실질 동작은 A와 같고 분류 라벨만 다름.
- C. 일부 글자를 전투로 환원(예: ㄴ지속 행 전체를 전투 버프로) — 필드 슬롯이 40자 이하로 줄어든다.

체감 판정은 실플레이·외부 테스트에서: "전투 중 손이 궁한가?"가 기준.
