## 1. 설계 원칙 — 오행부식 인력(引力) 사전

BotW의 명제를 그대로 채택한다: **플레이어는 자기 의지로 골랐다고 느껴야 하고, 실제로는 설계가 유도해야 한다.** 미니맵·마커가 없는 오행부에서는 이것이 선택이 아니라 생존 조건이다 — 유도 장치는 오직 지형·빛·색·소리·NPC다.

오행부의 인력 장치 목록(우선순위 순):

| 인력 | 오행부 구현 | 원전 대응 |
|---|---|---|
| 대형 삼각형 | 원경 산 실루엣(수묵 톤 램프 — 먹 덩어리로 읽힘). 백악·목멱·북한산·관악 | BotW 랜드마크 산 |
| 색 = 의미 | 수묵 단색 세계에서 **색을 띤 것은 전부 인력**: 주막 등불(따뜻한 주황), 오행 강조색(강토 기운), 단청, 마석 발광(청록) | 야간 자발광 시설 |
| 중형 삼각형 | 내사산 자락·언덕이 다음 경치를 차폐 — 고개·모퉁이를 넘어야 개방 | 원거리 차폐 |
| 소형 삼각형 | 근거리 바위·둔덕·담장 — 걷는 템포 조절, 소소한 가림-드러남 | 게임 템포 |
| 연기·소리 | 용광로 연기 기둥(적로 방향), 물소리(나루 접근), 종소리(인정·파루 — 미결 톤과 연계 시) | — |
| 배달 의뢰 | 목적지 자체가 "목적에 따른 인력". 의뢰문에는 좌표가 아니라 **지리 서술**("동대문을 나서 개천을 따라…")을 적는다 | 목적 인력 |
| 여지도(M키) | 실지형과 topology 일치하는 대동여지도풍 지도 — 마커 없이 산줄기·대로·역참만 표기. 지도 읽기가 곧 내비게이션 | — |

**절대 규칙**: 가도는 직선으로 뻗지 않는다(굽은 길 원칙 — 엘든링 적사자성 문법). 목적지는 한 번 보여주고, 가렸다가, 더 크게 다시 보여준다.

## 2. 세 가지 척도 — 한양 실측 기반 스케일

BotW가 교토를 걸어 잰 것을 오행부는 한양으로 한다. 실지형 왜곡은 허용(사용자 승인)하되 **압축률을 상수로 고정**해 지도-체감 일치를 지킨다.

- **거리감 — 압축률 [가정]**: 도성 안(시가) **1/10** (도성 직경 실제 약 4km → 게임 400m). 가도(교외) **1/25** (서울-개성 실제 약 60km → 게임 약 2.4km). 시가는 밀도가 높아 덜 압축하고, 가도는 주행 전제라 더 압축한다.
- **밀도감 — 배치 상수 [가정]**: 가도에서 차량(14m/s) 기준 **20~30초마다 시각 이벤트 1개**(주막·이정표·장승·폐가·습격 포인트·성소 입구 중 하나) = 약 300~400m 간격. 도보 구간은 6m/s 기준 같은 체감이 되도록 **120~180m 간격**. 이 상수보다 성기면 지루하고 빽빽하면 오픈월드 체감이 죽는다.
- **척도감 — 시설당 소요 [가정]**: 주막(체크포인트) 30초 체류 / 시전거리 한 바퀴 3~4분 / 도보 포켓(성소) 20분 / 도보 포켓(던전·보스) 30~40분 / 배달 한 사이클 5~10분.

속도 기준(실측): 도보 4m/s·질주 6m/s(StarterAssets) / 마석 자동차 최고 14m/s(VC_MagicStoneCar).

## 3. 전체 지리 — 왜곡 방침과 다섯 강토 배치

한반도 중부를 **황경(한양) 중심 방사형**으로 재구성한다. 실지형에서 가져올 것은 산의 방위·상대 높이·강의 흐름이고, 버릴 것은 절대 거리다.

```
                 [개성·송악산]  ← 후반 개방(현강 방면)
                      |
              임진강 --+--     (도하 관문)
                      |
   북한산 산괴 ██████ 무악재   ← 정북은 벽, 서북 고개만 길
              ██  백악  ██
 [철옹·西] — 돈의문 [황경] 흥인지문 — [청림·東]
   (마포·양화)   목멱(남산)      (중랑천 평야)
                 |
              한강 --- 나루     (도하 관문)
                 |
              관악 능선
                 |
              [적로·南]
```

| 방위 | 강토 | 실지형 근거 | 지형 저항 | 개방 시기 |
|---|---|---|---|---|
| 중앙 | 황경(토) | 한양 도성 안 | — (허브) | 시작 |
| 동 | 청림(목) | 낙산(125m)만 넘으면 중랑천 충적 평야 | **최저** — 가장 순한 출구 | **1차 인접 강토(확정)** |
| 남 | 적로(화) | 목멱 자락 → 용산 벌 → 한강 도하 → 관악 동측 우회 | 낮음 + 강 관문 | 2번째 |
| 서 | 철옹(금) | 돈의문 → 아현 → 마포·양화 한강 하류 저지 | 낮음 | 3번째 |
| 북서 | 현강(수) | 무악재 고개 → 구파발 → 임진강 → 개성 | 고개+강 이중 관문 | **후반** |
| 정북 | (길 아님) | 백악 뒤 북한산 산괴 | **최고** — 도전 지대 | 상시 진입 가능·비권장 |

**이중 링 난이도 지리**: 내사산 링(낙산·목멱·인왕 자락, 낮음) = 초중반 선택 산길 — 지름길·성소·수집물(해례본류)을 숨기고 중간 강도의 적을 둔다. 외사산 링(북한산·관악) = 고난도 도전 — 좁은 능선·낙사 지형(낙사 피해 시스템 기구현) + 강적. "산으로 가면 불편+강적, 그러나 보상" 원칙을 두 단계로 깐다.

## 4. 시작과 첫 30분 — 남로 입성 시퀀스 (확정)

기획서 도입부(§4: 길 위 → 첫 작도 → 차패 결계 → 도착지 훅)를 지리에 앉힌다. **시작점은 남쪽 삼남대로, 한강 남안(南岸)** — 이유: ① 첫 여정이 "강을 건너 수도에 든다"는 가장 강한 개방 연출을 지님 ② 남→북 진행 시 숭례문-시전-육조거리-백악이 한 시선축으로 꿰임 ③ 동쪽(1차 인접 강토)을 아껴둘 수 있음.

분 단위 시퀀스(전부 [가정], 괄호는 유도 기법):

1. **0:00 길 위에서** — 마석 자동차 운전석, 남쪽 가도. 정면 원경에 관악 능선이 등 뒤로 멀어지고, 전방 지평에 **목멱(남산) 봉수대의 연기 한 줄기**(대형 삼각형 + 연기 인력). 관보 음성이 흐른다.
2. **2:00 첫 위협·첫 작도** — 길가 습격(오염 요괴 1). 하차 유도, 「가」 튜토리얼. 쓰러진 자리 뒤 언덕(소형 삼각형)에 첫 수집물을 슬쩍 보이게(색 인력 — 먹 세계 속 낱장 하나).
3. **5:00 한강 첫 개방** — 굽은 길이 언덕을 돌면(차폐 해제) **한강이 화면 절반을 차지하는 수묵의 대여백**으로 열린다. 강 건너 도성 성벽과 숭례문이 처음 보인다(중형→대형 개방, 엘든링 "사각형" 임팩트). 나루터의 등불만 색을 띤다.
4. **7:00 나루 도하** — 차량은 나룻배에 실린다(강제 도보 구간 = 페이스 전환). 뱃전에서 도성 스카이라인 감상(강 위는 은은한 안개 — 원경 한지 페이드가 자연스럽게 작동).
5. **9:00 차패 결계** — 숭례문 앞 검문. 차패 제시 → 결계 개방(디제틱 UI 튜토리얼). 문루를 **지나는 순간** 시전거리의 소음·색(단청·등불·인파)이 확 열린다(문 = 사각형 개방 연출).
6. **10:00~ 황경 훅** — 배달소(수주처)에서 화물 인계 → 기록 불일치 훅. 이후 자유. 배달소 문 앞에서 **육조거리 시선축**(§5)이 정면에 놓이도록 출입구 방향을 잡는다.

## 5. 황경(허브) — 시가 400m의 인력 배치

구조: 실제 한양의 골격을 1/10로 — 숭례문(南 입구), 흥인지문(東 출구), 돈의문(西 출구), 육조거리-경복궁-백악(북쪽 시선축), 개천(청계천, 동서 물길), 낙산 언덕(東 내부 전망대).

- **육조거리 시선축(핵심 비스타)**: 시가 어디서든 북쪽을 보면 골목 끝에 백악 삼각형이 걸리고, 육조거리에 서면 **경복궁(오행부 본청) 지붕 위로 백악이 정확히 얹힌 정면 구도**(실제 한양의 축 그대로). 메인 서사(오행부 내부 은폐)의 무대를 항상 시야 끝에 두는 장치.
- **개천(청계천)**: 동서로 흐르는 물길 = 시가 내 방향 감각의 척추. 물길을 따라가면 반드시 흥인지문(東 출구)에 닿는다 — 길 잃음 방지 장치(노마커 보완).
- **낙산 언덕**: 시가 안에서 유일하게 올라가는 낮은 언덕. 정상에서 **도성 전체 + 사방 출구가 한눈에** — "지도를 실물로 보는" 조망점. 해례본 낱장 1과 성소 1을 배치해 등반 보상 [제안].
- **거점**: 배달소(수주)·시전 상인(강화·소모품)·주막 2(체크포인트)·관아(방榜)·경복궁 앞(서사, 진입은 후반 게이팅).
- 시가 밀도는 가도보다 3배 — 골목 모퉁이마다 소형 차폐(담장·처마)로 "몇 걸음마다 새 프레임"이 생기게. 실존 양식(기와 지붕의 반복, 성벽의 규모)이 곧 몰입 장치(엘든링 교훈 — 규모의 힘).

## 6. 방위별 출구 — 「처음 보는 풍경」 지점표

각 출구는 **문(차폐 최대) → 굽은 길 → 개방(그 강토의 첫 인상)** 3박자로 통일한다. 표의 "첫 풍경"이 이 문서의 심장이다 — 강토의 오행 기운을 색·지형·소리로 한 화면에 압축한 컷.

| # | 지점 | 트리거 위치 | 처음 보는 풍경 | 기법 | 상태 |
|---|---|---|---|---|---|
| E1 | 흥인지문 밖 | 문루 통과 직후 | **중랑천 평야가 수평으로 활짝** — 먹빛 세계에 처음 보는 **초록 담채의 숲 기운**(청림·목)이 지평선을 물들이고, 아차산 능선(대형 삼각형)이 동쪽 끝을 받친다. 평야를 가로지르는 가도와 장승 행렬 | 사각형 개방(문) + 색 인력 | 1차 구현 |
| E2 | 살곶이 들 굽이 | 동쪽 가도 중간, 개천 합수 굽이 | 처음으로 **거대 수목**(청림 어귀의 신목)이 가도 정면에 — 나무가 산보다 큰 위화감으로 "여기부터 목(木)의 땅" 선언 | 굽은 길 + 대형 삼각형(식물판) | 1차 구현 |
| S1 | 목멱 자락 모퉁이 | 남쪽 출구, 남산 서록을 도는 순간 | **한강 대여백** — 화면 하단 절반이 비어 있는 수묵의 강. 나루 등불 하나만 색. 강 건너 관악 능선 뒤로 **붉은 담채의 연기 기둥들**(적로·화의 용광로) | 차폐 해제 + 연기 인력 | 2차 |
| S2 | 나루 도하 중 | 뱃전(강 중앙) | 강 상류·하류가 양쪽으로 트이며 동쪽 살곶이·서쪽 마포가 동시에 보임 — "세계가 이어져 있다" 각인 | 강 = 열린 회랑 | 2차 |
| W1 | 돈의문 밖 아현 고개 | 고개 마루 | **한강 하류의 은빛 물길**이 서쪽으로 뻗고, 하류 끝 철옹의 **회백 금속 실루엣**(금·요새)이 원경에. 물길과 가도가 나란히 달리는 구도 | 고개 개방 + 대형 삼각형 | 3차 |
| N1 | 무악재 진입로 | 인왕-안산 사이 골짜기 초입 | 좁아지는 협곡 + **결계(차패 검문)** — 후반까지 닫힘. 틈새로 북쪽 하늘만 보여 "저 너머"를 각인 | 차폐 최대 + 게이팅 | 후반 |
| N2 | **무악재 마루** | 고개 정상(후반 개방 시) | **게임 최대 개방**: 임진강 유역이 발아래 펼쳐지고 지평 끝 **송악산(개성)** 이 먹 실루엣으로. 현강(수)의 검푸른 담채가 북쪽 전체를 물들임 | 최장 차폐 후 최대 개방(카타르시스) | 후반 |
| N3 | 임진나루 | 임진강 남안 | 폭이 한강의 두 배인 검은 강 + 잔월회 기관 감시탑 실루엣 — 차패 무효지 직전의 "돌아가려면 지금" 연출 | 강 관문 + 적 실루엣 인력 | 후반 |
| X1 | 백악 뒷길 초입 | 도성 북벽 암문(暗門) | 길이 아니라 **바위 능선** — 북한산 주봉이 압도적 크기로 (대형 삼각형의 위협 버전). 강적의 울음소리 | 인력의 역설계(경고) — 그래도 오르는 자에게 보상 | 상시·비권장 |

「지역을 벗어날 때」의 공통 경험: 문·고개·나루 중 하나를 반드시 지나며(경계 의식), 지나는 순간 **그 강토의 오행 색이 처음으로 화면에 든다**. 세계가 먹빛이라 담채 한 줌으로 충분하다 — 색의 양이 아니라 "처음"이라는 사실이 인상을 만든다.

## 6.5 청림(東·목) 내부 개요 [가정]

1차 인접 강토 확정에 따라 골격만 먼저 적는다(상세는 블록아웃 병행 별도 절).

- **지형 서사**: 평야(중랑천 들) → 숲 어귀(신목 E2) → **깊은 숲**(수관이 하늘을 덮어 낮에도 어둑 — 원경 페이드가 숲 안개로 작동) → 숲 심장부(청룡 영역). 들어갈수록 초록 담채가 짙어지다, 심장부에서 오염으로 **먹빛으로 되돌아가는** 반전(번영의 이면 테마).
- **구성 [가정]**: 어귀 마을(주막·배달 거점) 1 / 성소 1 / 던전 1(오염 신목 뿌리 — M2 보스) / 선택 포켓 1(숨은 계곡). 자음군 확장은 폐지(사용자 확정 2026-07-27 — 전 자모 시작부터 사용 가능), 청림 해금 보상은 **목 속성 마석 등급·도면·강화**로 일원화.
- **길 문법의 변주**: 황경-가도가 "열린 리본"이라면 청림 내부는 "덮인 회랑" — 수목이 중형 삼각형 역할을 대신해 차폐가 훨씬 잦고, 개방은 숲 틈의 빛기둥으로. 가도 주행도 숲길에선 감속 구간(뿌리·쓰러진 나무)을 둬 도보 전환을 유도.
- 적: 목 속성 오염 요괴 중심(속박·덩굴 — 상극 금 술식 학습 유도. 금 술식은 처음부터 그릴 수 있으나 **저등급 마석이라 결정타가 못 됨** — 철옹에서 금 마석 등급 해금 후 재방문 시 같은 획이 강해지는 역전 체감).

## 7. 가도 디자인 문법 (동쪽 가도 = 원형)

1차 구현할 동쪽 가도(흥인지문→청림 어귀, 약 2.2km [가정])를 원형으로 삼아 전 가도에 적용:

- **리본 폭**: 주행로 8~12m + 갓길 지형 20~30m(하차 탐색 여지). 그 밖은 산줄기·수풀로 소프트 차단.
- **굽이 리듬**: 직선 최대 250m — 그 이상이면 굽이나 언덕을 넣는다. 굽이마다 다음 랜드마크가 "슬쩍" 보였다 가려진다(적사자성 문법).
- **밀도**: §2 상수(차 기준 20~30초/1개). 동쪽 가도 배치안 [가정]: 장승 무리(0.3km) → 주막 1 「살곶이 주막」(0.7km, 체크포인트) → 습격 포인트(1.0km) → 성소 입구(1.3km, 도보 포켓 분기) → 신목 굽이 E2(1.6km) → 청림 어귀 결계(2.2km).
- **분기 표식**: 도보 포켓 입구는 가도에서 보이는 **비정상 지형**(찢긴 장승·먹이 고인 웅덩이·색 있는 꽃)으로만 표시 — 간판 없음.
- **배달 변주**: 같은 가도를 화물 유형이 다르게 쓴다(시한 화물=최단 주행 / 봉인 화물=습격 강화 / 요인 호송=도보 동행). 지형 재사용의 핵심.

**배달 사이클 검산(확정 5~10분 기준)** — 동쪽 가도 2.2km가 목표에 드는지:

| 배달 예시 | 구성 | 소요 [가정] |
|---|---|---|
| 최단(시가 내) | 배달소 수주 → 시전 상인 인계 | 2~3분(하한 미달 — 튜토리얼·저보상 전용) |
| 표준(가도 편도) | 황경 수주 → 차량 주행 2.2km(2분 40초) → 살곶이/어귀 인계 → 귀환은 자유 | 약 6~7분. **목표 중앙값 적중** |
| 상급(포켓 경유) | 황경 수주 → 주행 → 성소 포켓 도보 인계(습격 1회 포함) | 약 9~10분(상한) |

→ 가도 2.2km 유지. 청림 심부까지 잇는 상급 의뢰는 10분 초과가 예상되므로 **중간 인계(어귀 마을 경유 분할)** 방식으로 상한을 지킨다 [가정].

## 7.5 배달 체인 — 귀로를 설계하지 않는다 (확정 2026-07-27)

**배달을 완료한 그 지점에서 다음 배달을 수주한다.** 모든 거점(주막·마을·관아)이 수주처를 겸하고, 의뢰 체인은 순환 노선을 그린다 — 플레이어는 전진만으로 세계를 한붓그리기로 꿰고, "갔던 길을 되짚는 왕복"은 구조에서 제거된다.

- **순환 노선 원칙**: 체인의 3~4번째 의뢰는 반드시 출발 거점 방향으로 되돌아오게 짠다(황경→어귀→성소→어귀→황경). 단, 되돌아오는 다리 구간도 "새 의뢰의 편도"이므로 심리적으론 전진이다.
- **같은 길의 재사용 정당화**: 반복 주행하게 되는 간선(동쪽 가도 등)은 **월드 침식 단계**(여정 문서 §7 — 진행 지점마다 풍경·적·의뢰 내용이 변함)가 다른 풍경을 보장한다.
- **지름길 해금(소울라이크 루프백)**: 유지하되 용도를 한정 — 배달 노선이 아니라 **사망 회수·탐험 편의**용. 도보 포켓·산길 개척 시 가도로 되떨어지는 지름길이 열리고(무너진 다리 뭄 상설화, 잠긴 사잇문 — §8.5), 여지도에 실선으로 추가된다.

## 8. 도보 포켓 문법

- 진입은 반드시 **좁아졌다 열리는** 구조(협곡·문·숲 틈) — 가도의 개방감과 대비.
- 내부 척도: 성소 20분 / 던전 30~40분(§2). 공간 지름 100~200m를 수직·중첩으로 감아 체감을 늘린다(면적이 아니라 동선 길이로).
- 포켓의 끝에는 반드시 **밖을 내다보는 조망**(왔던 가도나 다음 강토가 보임) — 위치 감각 회복 + "다음 목적지" 인력 재장전.
- 체크포인트(주막·성소)에서 사망 회수 루프가 감당 가능하게 — 포켓 입구에서 보스까지 도보 90초 이내 [가정].

## 8.5 필드 작도의 지형 편입 — 술식이 길을 만든다

기구현된 필드 작도(음+받침 45자 체계, 뭄 돌다리·굼 도약·언 낙사 방어 + 앵커 시스템)를 맵 문법의 정식 재료로 편입한다. 원칙: **앵커는 레벨 디자이너의 붓** — 지형이 막고, 술식이 연다.

- **뭄(돌다리)**: 지름길 해금의 표준 장치(§7.5). 끊긴 다리·계곡 틈에 앵커를 심어 "보이는데 못 가는" 인력을 만들고, 건너면 루프백이 열린다. 청림의 개천 지류·계곡이 1차 배치처.
- **굼(도약)**: 수직 지름길(절벽 위 성소·성벽 위 길). 내사산 산길의 "지형 불편"을 실력으로 상쇄하는 수단 — 산길 도전의 보상 접근에 사용.
- **언(낙사 방어)**: 외사산 고난도 능선의 낙사 리스크와 짝. 험지 설계는 "언 없이는 벌, 언이 있으면 길"이 되도록 낙차를 잡는다(안전 낙하 12m/s 기준 역산).
- **표식 노출 규칙 [가정]**: 권장 위치 표식(바닥 먹 문양)은 가까이 가야 보인다 — 원거리 인력은 어디까지나 지형(끊긴 다리 그 자체)이 담당하고, 표식은 도착 후의 확인 장치. 미구현 41자 확장 시(§매핑계획 2차: 먼·건·운·숨·엄) 같은 원칙 적용.

## 9. 구현 로드맵 (M2 스코프 정렬)

1. **황경 시가 블록아웃**(ProBuilder) — 성벽 사각 + 4문 + 육조거리 축 + 개천 + 낙산 언덕. 기존 마을 프로토의 배달·수주·상점 배선 이식.
2. **남로 프롤로그 리본**(0.8km 축소판) — 시작 시퀀스 1~6 검증(한강 개방·나루·숭례문 입성).
3. **동쪽 가도 2.2km + 청림 어귀** — §7 원형 구현, 주행 페이스 실측(2분 30초가 적정한지 사람 판정).
4. **도보 포켓 2개**(가도 성소 1 + 청림 던전 1) — §8 문법 검증.
5. 여지도 UI 재제작(§9.5).
6. 이후: 남로 확장(적로) → 서로(철옹) → 무악재·개성길(현강, 후반).

씬 구조: 황경 씬 / 가도+강토 씬 Additive [가정]. 지형은 블록아웃까지 평면+메시, Terrain 도입은 룩 확인 후(사람 판정).

### 9.5 여지도 UI 제작 사양 (사용자 확정 2026-07-27)

대동여지도 원본을 그대로 쓰지 않는다. **게임의 실제 topology(§3 배치도)를 밑그림으로 그리고, 그 위에 대동여지도의 표기 문법을 스킨으로 입힌다** — 산줄기는 연첩 표기, 대로는 단선+역참 점, 물줄기는 쌍선, 읍치는 원 기호. 현재 M키의 Recraft 생성 지도(A/B안)는 이 정식판이 나올 때까지의 임시 스탠드인.

- 제작 순서: 블록아웃 확정 → 부감 캡처로 실 topology 추출 → 대동여지도 문법으로 재작화(Recraft 이미지-투-이미지 또는 사람 작화 — 아트 판단은 사람) → M키 스프라이트 교체.
- 갱신 규칙: 지름길 개척·강토 개방 시 지도에 실선·기호가 추가되는 **판본 갱신** 연출 [제안] — 수집·개척이 지도에 남는 보상(§7.5와 연동). 구현은 지도 스프라이트 레이어 합성으로.
- 표기 원칙: 마커·플레이어 위치 없음 유지. 지명은 붓글씨 라벨(한글 위주, 한자 병기 [가정]).

## 10. 확정 · 미결

**확정(사용자, 2026-07-27)**
- 배달 사이클 목표 5~10분(§7 검산 기준).
- 1차 인접 강토 = 청림(東).
- 시작 = 남로(한강 남안) 입성 시퀀스.
- 여지도 UI = 실 topology + 대동여지도 스킨 재제작(§9.5). 현행 생성 지도는 임시.
- 자음군 확장 폐지 — 전 자모 시작 개방, 해금은 마석 등급·도면·강화(§6.5).
- 귀로 설계 폐지 — 배달 체인(완료 지점 수주, §7.5).
- 진행 연동 월드 침식 도입 — 중반부터 기존 지역이 변한다(여정 문서 §7).

**미결 · 사람 판정 대기**
- 인왕산 산군 배치(1차 옵션 vs 청림 완전판) — 무악재 초입과 지리적으로 인접하다는 사실만 기록, 결정하지 않음.
- 황경·조정 톤(인정·파루 종소리 연출 앵커) — 채택 시 §1 소리 인력에 편입.
- 청림 던전·보스 실체(§6.5는 골격 [가정] — 오염 신목·청룡 위상은 기획 확정 필요).
- Terrain 도입 여부(블록아웃 룩 확인 후).
- 압축률·밀도 상수 — 블록아웃 실측 후 조정.
