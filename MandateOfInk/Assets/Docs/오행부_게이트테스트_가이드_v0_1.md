# 오행부(五行符) — M1 게이트 테스트 가이드 v0.1

외부 테스터 5인용. 플레이 후 각 문항에 답해 주세요. 소요 약 20~30분.
(배포 시 PDF 변환본을 전달한다 — 본 MD는 리포 원본)

## 1. 실행

- `MandateOfInk_Gate.exe` 실행 (Windows 64bit).
- 프로토타입 빌드입니다 — 그래픽은 임시(회색 박스 + 수묵 포스트), 사망해도 부활하지 않습니다(재시작).

## 2. 조작법

| 입력 | 동작 |
|---|---|
| WASD / 마우스 | 이동 / 시점 |
| Left Shift 짧게 탭 | 회피(무적 대시) — 길게 누르면 질주 |
| 좌클릭 | 평타 — 붓 자루로 후려치기. 적중 시 먹 충전 |
| Q 홀드 + 마우스 드래그 | **작도** — 시간이 느려지고 화면에 한글을 긋는다. Q를 떼면 발동 |
| R 홀드 | 먹 갈기(비상 충전) — 도중 피격 시 취소 |
| Tab | 락온 토글 |
| 1 / 2 / 3 | 부적(즉발) — 수량 제한 |

## 3. 작도 글자 일람 (이 빌드에서 뚜렷이 동작)

- 공격: 「가」(목) 「나」(화) 「마」(토) 「사」(금) 「아」(수) — 단일 투사체. ㅗ 계열(고·노·모·소·오)은 광역 파동.
- 방어: 「거」「너」「머」「서」「어」 — 전방 막(1.2초). ㅜ 계열은 돔.
- 받침: 「각」=속박 / 「난」=지속 피해 / 「맛」=관통 / 「강」=연쇄 / 「검」·「감」 등 ㅁ받침 = 격발 표식 설치.

## 4. 테스트 순서

1. **광장**: 이동·회피·작도 감각을 자유롭게 익힌다 (5분).
2. **북쪽 방(허수아비)**: 글자를 하나씩 그려 발동을 확인한다. 빠르게/느리게/대충 그려보며 품질·약발동 차이를 본다.
3. **서쪽 방(졸개 2)**: 예비 동작(진홍=느림/주황=빠름)을 읽고 회피·**받아치기**(적 공격 직전에 상극 방어 진 — 졸개는 금(金)이므로 화 「너」가 정답)를 시도한다. 표식(「검」) 설치 → 공격 글자로 격발 콤보도.
4. **동쪽 대형 방(보스)**: 메카천수관음과 교전. 팔 내려찍기를 보고 피하기. 체력 절반 이하의 변화 관찰.

## 5. 검증 문항 (전투코어루프 §13)

각 문항에 1~5점(1=전혀 아니다, 5=매우 그렇다)과 한 줄 코멘트.

1. 받아치기 — 적의 느린 예비 동작 안에 상극 글자를 그어 막는 것이 가능했다.
2. 저스트 체감 — 아슬아슬하게 막았을 때의 보상(먹 환급·큰 휘청)이 느껴졌다.
3. 공격 구분 — 빠른 공격과 느린 공격이 「피할 것 vs 받아칠 것」으로 직관적으로 읽혔다.
4. 먹 경제 — 잘 싸우면 먹이 마르지 않고, 난사하면 말랐다. 마르면 평타로 되살릴 수 있었다.
5. 평타 역할 — 평타가 「약하게 치고 먹을 깨우는」 동작으로 읽혔다.
6. 모드 가독성 — 붓끝(작도)과 자루끝(평타) 자세 차이로 지금 상태가 한눈에 읽혔다.
7. 작도 손맛 — 대필의 무게감(출렁임)이 묵직하고, 그은 대로 정확히 인식됐다.
8. 상합(격발) — 표식을 심고 터뜨리는 콤보가 전투 속도 안에서 굴러갔다.
9. 받침 글자 — 「각」「검」 같은 받침 글자가 받침 없는 글자보다 얼마나 느렸나(체감).
10. 1인칭 가독성 — 대형 보스·다수전에서 상황이 읽혔다.

## 6. 자유 기술

- 가장 재미있던 순간 / 가장 답답했던 순간.
- 붓·작도가 「먹으로 글씨를 쓰는」 느낌이었는가.
- 버그·이상 동작 (재현 방법 포함하면 최고).
